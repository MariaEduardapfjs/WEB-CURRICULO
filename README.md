# 📄 Meu Currículo Web - Maria Eduarda Pires Ferreira

Este é o meu currículo web, desenvolvido em HTML, CSS e JavaScript. Eu quis um design moderno e interativo, inspirado em interfaces de usuário retrô, e escolhi uma paleta de cores em tons de verde para dar um toque especial.

## ✨ Sobre o Projeto

Criei este currículo para destacar minha experiência em administração e minhas habilidades em desenvolvimento Front-End. Ele reflete minha paixão por tecnologia e meu compromisso com a inovação.

## 🎨 Design e Estilo

O design segue uma estética de "janela de sistema operacional" com elementos visuais que remetem a interfaces clássicas, como os botões de controle (vermelho, amarelo, verde) e a tipografia marcante.


## 🚀 Tecnologias Utilizadas

*   **HTML5:** Usei para estruturar todo o conteúdo do meu currículo.
*   **CSS3:** Responsável por toda a estilização, incluindo a responsividade e os efeitos visuais.
*   **JavaScript:** Implementei pequenas interações e animações (como os efeitos hover).

## 📁 Estrutura do Projeto

O projeto é composto pelos seguintes arquivos:

| Arquivo | Descrição |
| :--- | :--- |
| `index.html` | O arquivo principal com a estrutura e o conteúdo do meu currículo. |
|`Arquivos JPG ou PNG` | Arquivos de imagens para sua foto do curriculo e portifolio  |
| `README.md` | Este arquivo, com informações sobre o projeto. |
| `style.css` | O arquivo de estilos que define a aparência e o layout. |
| `script.js` | O arquivo JavaScript para interatividade e animações. |

## 🛠️ Como Visualizar

Para visualizar meu currículo, basta abrir o arquivo `index.html` em qualquer navegador web moderno.

```bash
# Certifique-se de que todos os arquivos estejam no mesmo diretório
open index.html
```

## ⚙️ Personalização

Se você quiser usar este template, pode editar os seguintes arquivos:

1.  **`index.html`**: Para alterar o conteúdo textual (seu nome, experiência, educação, etc.) ou substituir as imagens (sua foto e QR Code).
2.  **`style.css`**: Para ajustar cores, fontes ou layout.
3.  **`script.js`**: Para modificar as animações ou adicionar novas funcionalidades JavaScript.
